# 🎬 Netflix Data Dashboard

An interactive **Netflix Data Analysis Dashboard** built using **Microsoft Power BI** to explore Netflix movies and TV shows through visual analytics.

## 📊 Dashboard Preview

![Netflix Dashboard](Screenshot.png)

## 📌 Project Overview

This project analyzes a Netflix dataset and presents key insights through an interactive Power BI dashboard.

The dashboard provides an overview of:

- 🎬 Total number of movies and TV shows
- ⭐ Ratings distribution
- 🎭 Genre analysis
- 🎥 Movie vs TV Show distribution
- 👨‍💼 Director information
- 📅 Content release-year trends
- 📺 TV show ratings

## 📊 Visualizations

The dashboard includes:

### 1. Movies vs TV Shows
A donut chart showing the distribution of Netflix content by type.

### 2. Total Shows
A card displaying the total number of titles in the dataset.

### 3. Total Ratings
A card showing the number of ratings available.

### 4. Genre Analysis
A bar chart showing the number of titles across different genre combinations.

### 5. Directors
A metric representing the number of directors included in the dataset.

### 6. Release Year Trend
A line chart showing how Netflix content has been distributed across release years.

### 7. Rating by TV Show
A bar chart showing the distribution of TV shows across different content ratings.
